# Code of Conduct

Contributors are expected to behave professionally and respectfully in issues, pull requests and project discussions.

We welcome technical disagreement, evidence-backed corrections and constructive code reviews. Harassment, threats, hate speech, discriminatory language, stalking, personal attacks and deliberate disclosure of private information are unacceptable.

Maintainers may remove abusive material or restrict participation when justified by the behavior and severity. Conflicts of interest in enforcement should be disclosed where possible.

For abuse on GitHub, use GitHub's **Report content** controls, which can be handled outside a public issue. If you need maintainer assistance, open a non-sensitive issue requesting a private channel rather than posting another person's personal details publicly. Serious immediate threats should be handled through appropriate local channels.

No enforcement response time is guaranteed.
