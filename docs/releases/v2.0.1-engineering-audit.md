# v2.0.1 principal engineering audit and remediation record

This document tracks the final code-level adversarial review of the **single v2.0.1 draft PR #63**. It does not constitute external human approval, authorize a merge or certify publication rights for source geometry.

## Audit scope

- **Correctness and data semantics:** five-level administrative identity conservation, duplicate names, deterministic order, parent relationships, stable JSON serialization and malformed dataset rejection
- **Algorithms and performance:** lazy ID and name indexing, scoped exact/prefix lookups, Unicode casefolding, grapheme-aware fuzzy ranking, cache limits and representative latency distributions
- **Memory and reliability:** bounded caches, repeated engine lifecycles, allocator measurements, failure cleanup and immutable staged writes
- **GIS and export fidelity:** GeoJSON array shape, finite coordinates, reviewed parent-to-polygon mappings, multi-format conversions and round-trip evidence
- **Security and PII:** untrusted UTF-8 inputs, file paths, symlinks, shell invocation, local acquisition restrictions and publication metadata
- **Compatibility and operations:** optional ext-intl behavior, no hidden ext-ctype dependency, PHP 8.2–8.5, Composer consumers, production dependency inventory and release provenance
- **Test depth and maintainability:** independent generated-data oracles, malformed-input mutations, exhaustive small-string edit-distance checks, PHPStan level 9, coding standards and strict PHPUnit deprecations
- **UX/authorization:** this is a headless PHP library with no hosted UI or user-role boundary. Results represent locations, not personally identifiable user records. Applications must not treat fuzzy matches as authorization or an authoritative source ID

## Existing controls rechecked

1. **Administrative data:** the full hierarchy fingerprint must match \`main\` by level, original ID, displayed name, parent ID and traversal order. Same-name records may never be deduplicated.
2. **Search algorithms:** preserve legacy exact and prefix contracts. Unicode mode is explicit and requires optional Intl. Fuzzy suggestions preserve source object references and return deterministic distance-ranked results.
3. **Performance:** compare identical baseline/candidate source using 16 query workloads. Collect cold latency, warm p50/p95/p99, warm mean and reserved memory. No single GitHub runner measurement guarantees a nanosecond SLA across environments.
4. **Memory:** profile constructor, full indexing, scoped cache churn, streaming, flattening and repeated engine creation. Reject growth beyond the recorded release budgets.
5. **API consumers:** plain Composer and Laravel container smoke tests install the package without requiring any Illuminate runtime dependency.
6. **CI:** unit and regression tests, PHPStan, coding standards, source integrity, Unicode cases, GIS conversions, release-candidate creation and SBOM checks must succeed on the final commit, not merely an older green revision.
7. **Filesystem:** immutable published export targets cannot overwrite an existing name or follow dangling symlinks. Incomplete staged writes are rejected and unpublished files are cleaned where execution can recover.
8. **Publishing:** local-reviewed geometry mappings are not automatic national coverage certification. An explicit independent rights assessment remains mandatory for redistribution.

## Residual limitations outside the code audit

- \`resources/releases/readiness-template.json\` intentionally contains pending external approvals. The readiness assessor always reports \`release_ready: false\` without human-reviewed evidence. A fully green PR is **not** equivalent to source-rights approval, national boundary verification, prerelease Packagist installation or permission to tag a release.
- GitHub branch-protection settings could not be confirmed through the available integration. Do not assume the repository enforces all CI checks as required merge checks until independently inspected.
- The existing contributor README automation under \`.github/workflows/main.yml\` uses an external action and repository token. Consider immutable action SHA pinning and explicit least-privilege permissions in a focused operational-hardening change.
- Candidate benchmarks exercise bounded representative workloads. They do not prove that all possible inputs have optimal theoretical complexity or identical performance on every host.
- This audit is an adversarial code and automated-evidence review. It does not represent a second human reviewer or operational deployment signoff.
